URL 
------
https://google.com/kohli/56?id=2?name=leo

google.com --> domain 
/kohli --> path
/56 --> params
?id=2 --> query

Method
---------
GET --> Retrive
POST --> To Send data
PUT --> UPDATE a data
PATCH --> Update a part of data
DELETE --> DELETE

Endpoint --> Method + path(/keyword)

Header 
--------
>> contain additional information about the request
("Authorization")

Status code 
-----------
it tells the client about the response.
2**  --> Success 
3** --> Redirected
4** --> client error (404)
5** --> server error

Authentication 
------------------
>> It verifies users identity.

Authorization 
---------------
>> It happens after Authentication. it decides what user is allowed to do

Sign Up --> registering yourself (username, emailId, pass)
Log in --> entering the app using the credential

when you access protected resources --> app verifies you.
Client(Signup) --> Server(encrypt the pass) --> DB
Client (Log in (credentials)) --> Server(token) --> Client(token)
