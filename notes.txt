Node 
-----
>> A runtime environment that allows JS to run outside the browser.
command to execute JS --> node fileName.js

JavaScript 
------------
>> Single Threaded, Dynamically typed, event-driven Programming Language.

frontend ---> events happening in page (click, mouseover) --> JS triggered
server --> events happening in the server (req) --> JS triggered.

In built Objects 
-------------------
Frontend --> document, console....
Node ---> fs, path, console......

Asynchronous Operations (Event Looping)(non blocking IO)
---------------------------
Synchronous Operations --> immediate tasks

HTTP Module 
------------
HyperText Transfer Protocol

It is a communication protocol that allows clients and servers to exchange informations.

Client(webpage, mobileApp, Postman)
--Req-->
Node(Server)
--Res-->
Client

URL 
------
https://google.com/kohli/56?id=2?name=leo

google.com --> domain 
/kohli --> path
/56 --> params
?id=2 --> query

Method
---------
GET --> Retrive
POST --> To Send data
PUT --> UPDATE a data
PATCH --> Update a part of data
DELETE --> DELETE

Endpoint --> Method + path(/keyword)

Header 
--------
>> contain additional information about the request
("Authorization")

Status code 
-----------
it tells the client about the response.
2**  --> Success 
3** --> Redirected
4** --> client error (404)
5** --> server error

JSON
------
>> JavaScript Object Notation.
"{"name":"ken","age":"72"}"

-----
